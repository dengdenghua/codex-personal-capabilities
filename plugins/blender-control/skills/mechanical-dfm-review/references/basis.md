# 标准、供应商资料与工程经验



核查日期：2026-10-22。标准资料只核官方范围/目录，未核数值表和规范全文；未确定采用关系前为S?候选。



- **P1 [ISO 20457:2026](https://www.iso.org/obp/ui?_escaped_fragment_=iso%3Astd%3Aiso%3A20457%3Aed-2%3Av1%3Aen)**：塑料成型件公差与验收条件。公开目录定位5.5拔模、6章工艺可达精度、7.3分型/模具错位、8章一般公差；条款内容和取值待原文核对。它不是机加工/钣金通用标准，也不是所有塑料的统一模具参数表。2018版已被2026版替代，项目旧版约定不得擅自换版。

- **P2 [ISO 16792:2021](https://www.iso.org/standard/73871.html)**：数字产品定义数据入口。发布图纸还需项目选定的制图/公差规范，不因使用本清单自动采用ISO体系。

- **E1 [Protolabs 注塑设计指南](https://www.protolabs.com/resources/guides-and-trend-reports/injection-molding-guide-process-design-tips-materials/)** 与 [拔模建议](https://www.protolabs.com/resources/design-tips/improving-part-moldability-with-draft/)：制造商经验，已查壁厚过渡、筋柱、脱模与工艺相关建议；不是法规，也不保证其他供应商工艺能力。本skill不固化其数值为企业标准。



钣金、CNC、压铸和表处项目未在本次核实到适用的具体标准正文，均按E或批准的供应商/项目规范执行。需要焊接、材料安全、阻燃、环保或耐蚀认证时另选对应标准和版次，不把本表自动扩大为该认证审核。
