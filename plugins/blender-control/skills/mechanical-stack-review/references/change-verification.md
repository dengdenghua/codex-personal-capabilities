# 修改与替换的验证

适用：机械零件的尺寸/位姿修改、未核验历史零件替换、跨版本合装。属于工程方法，不是新增法规或审批流程。按实际变更限定检查范围；用户只要求隐藏、截图、改名或另存时，不触发全机重设计。

## 先定义“改对”的含义

- 从用户要求列出本次目标、固定基准/孔位/光轴、允许改变的零件与关联件。分清“保留安装孔和高度”与“保留旧外形全部材料”，后者不是前者的默认实现方式。
- 确认旧件、新件与当前总装各自的版本、坐标系及配套条件。源版本的验证只适用于其当时配置，不能自动转移到混合总装。用户已指定版本就采用，不擅自追逐更高编号。
- 在建模前选能验证设计意图的方法。例如加宽板件要求连续外轮廓和原孔槽不变，除了宽度，还需检查新旧边界、拐角和孔槽；不要等到代码完成后仅围绕实现写“通过”断言。

## 操作成功与设计正确分开检查

| 检查层次 | 能证明什么 | 不能据此证明什么 |
|---|---|---|
| 导入、保存、重开、对象数量 | 文件/操作完成 | 尺寸与结构正确 |
| 单位、世界基准、尺寸、实体有效 | 数据和几何基础有效 | 新轮廓合理、零件能装 |
| 增减材料区域、边界连续性、孔槽差异 | 修改是否符合预期 | 相邻零件仍配合 |
| 接触面、孔轴、紧固链、干涉与局部路径 | 指定接口和工况的装配状态 | 全机制造及实物已验收 |

布尔并集能得到有效单体但保留多余凹口。加宽/补料时查看交界局部正视或剖面；必要时从目标外轮廓重建，再转移原孔槽。差体积、有效性与包围盒是互补证据，不能替代目标轮廓检查；不把某项目圆角或余量设为通用数值。

## 跟随受影响的配合链

- 部件移动或换型时，检查它的支撑接触面、定位槽、安装孔、螺钉头/杆、垫片和嵌件。主件对中不代表底座、夹持件或螺钉已适配；邻件坐标保持不变也可能正是错误来源。
- 底板孔位固定时，不能只平移托座来消除外观错位。先核螺钉轴线和承托面；若必须改关联件，按用户已授权的小件/大件范围处理，超出范围再提出具体方案。
- 包围盒筛选近邻，实际干涉用有效实体或精度明确的网格。记录装配位姿、接触/允许压缩/禁止干涉分类、间距或交叠值及证据。薄壳需确认封闭性和实体解释，未封闭网格不直接当有体积实体。
- 截图箭头是问题定位，不能直接推断“悬空”或“干涉”。区分投影视角、边缘外伸、真实间隙和体积相交；结合近景与测量作答。
- 局部修改后重查受影响接口及保留项，无需无限扩大到无关系统；将未覆盖范围写清。

## 完成状态和错误复盘

隐藏、着色、记入待办不算修复。已知装配错误仍存在时，保留明确的失败状态，说明已改与未改项；不能只说“已保存并核对”让人理解为装配通过。用户指定“正式版”文件名照常执行，文件名不改变证据等级，也不额外要求命名审批。

解释修改失误时回答执行中的错误决策：误信哪个假设、遗漏哪个验证、何种结果被过度解释。“旧模型有问题”是来源描述，不能替代对本次直接复用与漏检的责任说明。将可迁移的预防动作写入技能；项目尺寸、实测结果及未解决事项留在带来源的项目记录。
