# 内部堆叠安规审查

面向机械建模中的安规预审。可用于 Blender、SolidWorks、STEP 装配或图纸；没有模型时先建立检查表。仅提出清单不要求启动 CAD 或修改模型。

本项目现为类似Eight Sleep的水循环睡眠温控产品。优先读取 [睡眠温控液体与潮湿专项](references/sleep-system.md)，先确认主机、柔性水垫与控制单元的产品标准分类。不能因有联网/PCB就默认采用AV/ICT安规；下方IEC 62368索引保留为其他产品的参考分支，不自动成为本项目判据。

## 工作入口

1. 确认产品类别、销售地区和认证采用版本。未提供时先输出通用预审，标记适用性待确认，不能默认所有电器适用 GB 4943.1。
2. 读取 [标准与证据](references/standards.md)，选定条款基线；本项目先走睡眠温控分类分支。只有确属AV/ICT的项目才使用GB 4943.1—2022入口与IEC 62368-1:2018已查索引，二者不能视作完全相同的条文。家电通用/专用部分及当地采用版须配套核对。
3. 使用 [内部堆叠检查清单](references/checklist.md)，按实际产品选择适用项目，保留不适用理由。
4. 需要测模型时读取 [建模测量规则](references/model-review.md)，调用当前可用的对应 CAD 控制 skill / MCP。先识别准确文件和版本，再测量；改变模型仍按该工具的保存与副本规则执行。
5. 用 [审查记录模板](assets/review-template.md) 输出结果。先交代高风险位置和缺失输入，再交付逐项清单及证据。用户只要求通用清单时，不编造某个产品的实测结论。

## 决策边界

- 先建立电气域和绝缘边界：市电一次侧、隔离后二次侧、可触及导电件、保护接地件、悬浮金属件。不能只按“强电/弱电”、PCB 外观或线色判定；低电压也可能有起火风险。
- 对每条边界分别记录电气间隙、爬电距离和固体绝缘。PCB 板间距、铜柱高度、网格包围盒间距均不能替代它们。
- 计算限值前取得工作电压 RMS/峰值与频率、瞬态/过电压类别、污染等级、材料 CTI/组别、海拔、所需绝缘等级。还需电气能量源/人员可触及性分类。缺项时限值写“待确定”，不能填写通用 3/5/8 mm 或抄其他产品报告的数值。
- 每个条款写明完整标准版本、证据等级和来源。目录或他人试验报告只能支持主题定位，不能声称已核对标准全文、数值表格、所有例外或国别差异。换版时重新核对。
- 标准要求、实现该要求的工程措施、企业设计裕量分列。不能把加扎带、统一螺纹胶、某种螺钉数量、固定弯曲半径或普遍振动试验当成所有产品的法规硬指标。
- 不把喷漆、阳极氧化、阻焊、导热垫或普通胶带自动计作安全绝缘；按实际材料、厚度、覆盖、保持方式及试验评定。金属件是否必须接地取决于保护架构，不能一律接地。
- 状态使用“通过（本检查项）/不通过/待确认/不适用”。仅当适用限值、几何真实性、材料及所需试验证据均充分时，才给相应项目通过；CAD 只可证明记录范围内的几何结果，不能直接宣告整机安规通过。

## 交付最低信息

每项记录对象 A/B 精确名称或图纸位置、电气域、危险场景、标准版本及条款、条款核验等级、限值及出处、名义/最差尺寸、材料/固定证据、状态、修改措施及待做试验。记录模型路径、版本、单位、测量方法和检查日期。涉及同一焊脚/螺钉的多个项目可以共用证据编号。
