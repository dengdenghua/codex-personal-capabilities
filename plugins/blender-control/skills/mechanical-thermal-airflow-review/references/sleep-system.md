# 睡眠温控系统：冷端、热端与整机能量预算

先确认TEC/压缩式/其他、单双区及共享水箱/换热器的结构。以下计算为E工程方法；试验V独立确认，不是标准规定的统一冷量或风量。

## 边界与计算

1. 画床面→循环液体→冷板/蒸发器→制冷单元→散热器/冷凝器→卧室空气的热流图；标明泵、电源、风扇热量进入水侧还是空气侧。
2. 单相且近稳态、无明显散热旁路的水侧换热可估算 `Q_water = m_dot * c_p * (T_return - T_supply)`，取实际液体温度/浓度下密度、比热；制冷时回水较暖为正。流量计读数需换算质量流量；小温差时校准差温与不确定度可能支配结果。瞬态还要计液体、床垫、金属等蓄热及环境漏热，不能用此式单独证明瞬态制冷量。
3. 对TEC或制冷单元的稳态边界，`Q_hot = Q_cold + P_unit`；P_unit是该边界输入功率，压缩式定义相应压缩单元边界。主机排热再加入直接进入空气侧、尚未计入的辅助损耗。已进入水侧且包含在Q_cold中的泵热不能再加一次。反向加热需重画边界与符号，不盲目沿用制冷公式解释全部热量。
4. 冷端需求包括实际耦合到水垫的人体负荷、床品/环境传热、循环液体与结构降温、进入水侧的辅助热；不能把人体全部代谢热当作床垫负荷。床面设定温度、水温与换热器温度不同。
5. TEC不能同时使用铭牌Qmax与最大温差作为实际工作点；用实际热端温度、冷端温度、电流与模块曲线。压缩式用相应工况性能图/循环及部分负载数据，不套TEC参数。
6. 取热端排热而非仅床面吸热匹配散热器、风扇工作点与箱体风道；考虑双区一冷一热、共用热端、排气回流、积尘、床下安装、靠墙及噪声约束。

## 补充清单

| ID | 检查项 | 依据/设计检查 | V/需试验确认 |
|---|---|---|---|
| THS01 | 热流边界 | E：主机/水路/床面各热源去向唯一标记，防重复计功率 | 能量预算与实测功率/热流一致性 |
| THS02 | 人体耦合负荷 | E：单双人、床品、姿态和环境分别定义 | 热模拟负荷及正常使用温度证据 |
| THS03 | 水侧量热 | E：实际液体比热、流量、差温、旁路及不确定度 | 校准稳态量热，差温过小不作高精度结论 |
| THS04 | 拉温与蓄热 | E：液量、床垫及结构热容和初温 | 冷热启动全过程功率/温度/流量时序 |
| THS05 | TEC/压缩式性能图 | E：实际工作点与控制/部分负载，不取虚构制冷架构 | 性能图相关性与台架COP/能力 |
| THS06 | 热端排热 | E：Qc加制冷输入及边界外辅助损耗，泵热不重复 | 热端温度/风量和整机功率联测 |
| THS07 | 水路与热端联动 | E：低流、气堵、散热阻塞及传感延迟 | 台架异常验证，故障保护另引TC专项 |
| THS08 | 双区冷热串扰 | E：共享热源/水箱/散热与床面耦合 | 两区相反设定、不对称负荷实测 |
| THS09 | 安装与环境 | E：床下、靠墙、脚边堵风、地面灰尘和海拔 | 批准环境/姿态下稳态及启停测试 |
| THS10 | 冷凝边界 | E：冷表面与被褥内露点/隔汽连通性 | CD专项环境实测，保温后重新核散热 |
| THS11 | 噪声性能折中 | E：夜间限转速可能降低制冷/排热能力 | 同一工况下枕位声压与温控同步记录 |
| THS12 | 安规分类与温限 | S?家电/专用标准；E：材料、接触温度、器件额定和设计裕量分开 | 适用正文核对及温升/异常试验 |
