# 水路与防泄漏验证计划骨架



本表是工程计划，不是标准试验原文。每行需补样机/固件/液体版本、数量、仪器、持续时间、载荷/温压及批准来源、停止条件和责任人；未补齐不执行依赖这些参数的极限试验。



| 阶段 | 验证目的 | 条件/控制变量 | 判据及关闭证据 |

|---|---|---|---|

| 设计包络 | 各支路最弱额定件与局部峰值 | 开式/闭式、高差、温度、液体黏度；工况来源 | 压力上限及允许漏量来自批准规范 |

| 静态检漏 | 接头/箱体/总成密封 | 预处理、温度稳定、夹具背景漏及仪器分辨率 | 漏率/保持时间待批准，压降不能独立归因 |

| 动态及困液 | 堵塞、挤压、快接困液、停泵虹吸 | 带保护的台架；测局部压力峰值和残液 | 不超部件允许条件；安全停止阈值先批准 |

| 保护联动 | 检测盲区及停机后残余风险 | 代表性位置/流失速率/传感器故障逐个注入 | 响应、残水去向及重启规则逐项满足目标 |

| 老化后与量产 | 端接、密封及检漏方法稳定性 | 冷热/寿命/运输序列按计划，测试前后同一方法 | 前后流量/泄漏/保持力对比；量产能力独立确认 |



故障试验用台架和独立监测，保护试验夹具与样机。确认传感数据有效后再升载；异常超出批准停止条件立即停止，不为获得通过重复提高阈值。报告保留原始时序、测点位置、异常与事后拆解；安全、性能和寿命判据分别关闭。
