# 冷凝与水汽管理验证计划骨架



本表是工程计划，不是标准试验原文。每行需补样机/固件/液体版本、数量、仪器、持续时间、载荷/温压及批准来源、停止条件和责任人；未补齐不执行依赖这些参数的极限试验。



| 阶段 | 验证目的 | 条件/控制变量 | 判据及关闭证据 |

|---|---|---|---|

| 露点风险图 | 全链路表面与局部空气 | 冷端/管线/接头/水垫各层，多点校准 | 计算裕量与实测不确定度分开记录 |

| 环境运行 | 高湿、最低水温及床面热湿负荷 | 条件来自产品环境与用户场景，非任意极限 | 可接受凝露量/位置/持续时间按项目定义 |

| 瞬态与维护 | 启动、停机、转移和快接复装 | 连续采样，并观察停机余冷阶段 | 不遗漏运行结束后的凝露峰值 |

| 湿态防护 | 液滴迁移及隐藏积湿 | 电气隔离/停止条件和试验方案先批准 | 按采用安规及工程湿害目标分别验收 |

| 长期及干燥 | 湿干循环、保温老化、停用 | 拆解/称重等区分外漏、渗透与吸湿 | 残湿、耐蚀与卫生证据不能由无滴水代替 |



故障试验用台架和独立监测，保护试验夹具与样机。确认传感数据有效后再升载；异常超出批准停止条件立即停止，不为获得通过重复提高阈值。报告保留原始时序、测点位置、异常与事后拆解；安全、性能和寿命判据分别关闭。
