# SolidWorks 修改正确性检查

用于尺寸/特征修改、零件替换和跨版本合装。只检查实际变更及受影响接口；纯显示、改名、另存不因此要求全机审计。本流程不增加审批，也不替代已有作业队列和资源规则。

## 先确定修改目的

- 写明目标轮廓/功能、不能改变的基准/孔位/轴线、允许修改的零件，以及对应配置。旧文件版本高、能重建或曾导出，不代表它适用于当前装配。
- “保留孔位及安装高度”不等于保留旧件每一块材料。加宽旧圆角板时，直接两侧加料可能产生凹口、台阶或薄颈；并集有效且包含旧体积，仍可能违背目标外形。
- 验证条件来自用户目标和接口，不只来自脚本已执行的步骤。尺寸、体积和实体数是基础检查，不能代替新旧边界与配合检查。

## 特征和几何修改

- 确认选中的文档路径、配置、特征及草图尺寸的实际含义；核对尺寸作用范围、方程、外部引用及派生配置，避免只改当前显示配置而遗漏交付配置。
- 拓扑变化后，旧面编号/边编号可能指向不同实体。重新核对配合与特征选择所用面的几何类型、基准位置和方向；“选中了一个面”或“API返回成功”不是选择正确。
- 修改驱动尺寸或草图时保留合理的约束关系；不能通过固定全部几何或压制失败特征掩盖问题。重建后检查特征错误、意外抑制、实体数、孔槽和实际增减材料区域。
- 查看修改交界的局部正视/剖视及整体预览。连续外轮廓是目标时，检查连接和圆角；若需重建外轮廓，单独保留原孔槽/基准并验证未误填孔、误切接口。不要把同体积或同包围盒当成形状一致。

## 装配依赖链

- 明确组件引用路径、引用配置、局部坐标和装配变换。只解析受影响的轻化/抑制组件；未参与求解或扫描的件不能算检查通过。
- 部件换型或光轴/接口位置调整后，跟查承托、定位槽、孔轴、压缩套、垫片和螺钉头/杆。其坐标未变不能证明适配；固定底板孔位时，不直接平移托座来消除视觉错位。
- 配合求解成功只说明约束可解，不证明接触正确或无干涉。分别核配合状态、应保留的自由度、接触间距和干涉；检查插入/拆卸路径限于变更影响范围。
- 真实实体/已知精度网格用于接触和干涉结论，包围盒仅筛近邻。允许接触、设计过盈、禁止碰撞分别标识；跳过扫描或组件未解析不记为零干涉。

## 保存和报告

- 重建所改零件及受影响装配；在授权交付范围内核图纸、BOM和中性导出引用的模型/配置。未同步的文件明确标识，避免只改SLDPRT就声称整机已同步。
- 按既有检查点流程核对最后一次重建后的子件及装配保存状态，保存并检查最终文件。文件可打开、STEP已输出和预览正常，分别只是对应检查项通过。
- 已知干涉未消除时保持失败/未解决状态。隐藏、着色和列待办不算修复；用户要求“正式版V01”可照常命名，名称不提升工程验收状态。
- 解释错误时说明本次误信的假设、漏掉的验证、被过度解释的结果。旧模型有缺陷不能替代对直接复用和漏检的说明。项目数值留在项目证据，不推广为通用阈值。
