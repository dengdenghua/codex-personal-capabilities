# 内部堆叠安规检查清单

对当前水循环睡眠产品先使用 [SAS01–SAS14专项](sleep-system.md) 确认分类和液体/潮湿/接触风险；下表中的A栏是IEC 62368主题，不能自动用于家电合规判定。

适用对象：PCB、金属支架/铜柱/螺钉、散热器和线束。条款基线与证据等级见 [standards.md](standards.md)。

**A 栏 = IEC 62368-1:2018 的 B 级主题索引。H 栏 = IEC 60335-1:2010+A1:2013 历史主题索引；换至当前家电版须重新核对。GB 4943.1—2022 具体对应条款均待正文映射（C）。**

每行是检查动作。表中“工程措施”是可选实现，不能当作标准逐字规定。限值一律来自项目实际采用文本和条件；不能给所有产品统一毫米值。可直接把本表复制进项目记录，再补上数值、材料、状态和证据。

## 预审输入

- [ ] 产品类别/型号/市场/采用标准版本与修订、目标认证及产品专用标准已确定。
- [ ] 输入电源（内置市电/外置适配器/电池）、额定及最大工况、保护类别、安装海拔和环境已记录。
- [ ] 有电气域图及原理图支持：一次/二次侧、保护地、可触及件、悬浮件；记录各绝缘边界的防护目标。
- [ ] 已取得间距判定参数：工作电压 RMS/峰值/频率、瞬态、污染等级、CTI/材料组别、海拔及所需绝缘等级；未取得的列“待确定”。
- [ ] 模型与实际版本一致，包含焊脚、焊锡、铜柱、紧固件、垫片、散热器夹具及线束公差；外观简模不足处标明。

| D02 | PCB ↔ 金属支架/螺钉：含板底焊脚及螺钉最长伸出 | 按金属件接地、悬浮、可触及的实际状态分配防护；记录最差空气距离 | 5.3.2；5.4.2；5.6 | 8；27；29.1 |

| D06 | PCB 多层结构、导电件间隔板、绝缘垫 | 区分表面距离与穿透固体绝缘；核材料、最小厚度及电气强度证据 | 5.4.4；5.4.9 | 29.3；16 |
| D07 | 绝缘片/套管的覆盖及保持：边缘、螺钉孔、压缩和移位后 | 核查规格、层结构、温度能力、固定及装配防错；最差位置不得绕过防护 | 4.4.3；5.4.4；5.4.4.6 | 22；23.6；29.3 |
| D08 | 导热垫/导热胶 ↔ 功率器件 ↔ 散热器 | 数据表及认可范围支持所需绝缘；纳入压缩最薄、刺穿、爬电边缘和热老化，不能只看标称耐压 | 5.4.1.4；5.4.4；5.4.9 | 11；29.3；30 |
| D09 | 表面涂层：阻焊、喷漆、氧化膜、三防漆 | 没有适用的绝缘评定，不把外观涂层计入安全防护；如依赖涂层，单列原文核验及试验 | 5.4.4；5.4.9 | 29 |
| D10 | 海拔/环境/频率变化对上述边界的影响 | 间隙海拔修正与爬电材料/污染判断分开；高频按相应条文复核，不能所有距离同乘海拔系数 | 5.4.1.5；5.4.2.5；5.4.3；5.4.4 | 29 |

- [ ] 所有未确定限值、缺失材料/网表、未知金属电位及待做试验均有明确责任项。
- [ ] 每个“通过”都有准确适用版本及足够证据；没有把上述 B/C 级索引改写成全文核验。
- [ ] 改版后复测受影响边界，保留原尺寸、修改尺寸、模型版本及截图定位。
