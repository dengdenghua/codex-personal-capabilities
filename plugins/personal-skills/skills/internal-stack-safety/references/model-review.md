# 从模型取得可复核的证据

## 模型准备

记录文件完整路径、版本、对象名称与单位。Blender 应核对 scene unit scale、对象缩放、修饰器后的 evaluated mesh、世界变换和链接实例；CAD 应核对配置、抑制/隐藏零件、柔性件及装配位姿。只读取模型时不强制另存，不为了截图污染用户模型。

电气属性来自网表、原理图和设计人员确认，不由材质颜色推断。需要时记录：object_id、electrical_domain、metal_state（PE/悬浮/可触及/待确认）、insulation_role、材料、真实几何/简模状态。金属支架接触涂层表面不能证明电气连接。

## 测量

- 包围盒仅用于筛选近邻；最终用实际实体面/边或经过精度验证的网格，输出两端点世界坐标、对象/面定位、最短值和单位。包围盒重叠不等于实体干涉。
- 安全间隙针对实际导电部位。计入板底突出焊脚、焊锡、铜箔、孔壁铜、螺钉头/尾、垫片、器件金属背板和夹具。缺失处只能报“几何不足”；不把 PCB 树脂板面直接当整个导电面。
- 直线被隔板阻断时，不能直接把穿过固体的欧氏距离报作空气间隙。应按采用标准的路径/测量规则处理隔板绕行、固定和开孔，同时单独评价固体绝缘。
- 爬电距离按允许的绝缘表面路径测量，并按原文处理槽、接缝、材料边界和污染条件。一般 CAD shortest-distance 功能不能自动证明爬电；未建准确路径就写“待确认”。
- 分别记录名义值与最差值。简化同轴尺寸链可用 `d_worst = d_nominal - sum(各项有界靠近量)`；空间旋转、翘曲与柔性变形用极限装配/包络复测。不得重复扣除已包含在包络中的公差。
- 不确定最差形变时，输出名义几何结果及缺失项，不能用任意裕量冒充试验形变。线束用线径、护套和可移动范围形成包络，不只测中心线。

## 固定与材料

模型可显示支撑数量、连接方式、覆盖、孔边、干涉和线束保持位置；不能证明扭矩、螺纹保持力、胶粘老化、CTI、耐压、接地连接电阻或阻燃等级。需图纸/BOM/数据表/试验对应证据。

有限元/热仿真与实测分别标记。没有电气域和目标限值时，可以输出“检测到几何接近/干涉”，不能自动写“触电风险不合规”或“安规通过”。

## 项目输出

交付逐项表格；风险截图附对象名和测量端点；必要时增加带版本的测量 JSON，包含方法、精度/网格误差、坐标、单位和模型来源。用户仅要检查清单时不生成多余测量脚本。需要改模型时先完成原状态记录，再保存工作副本并复测相关边界。
