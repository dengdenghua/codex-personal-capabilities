# 水循环睡眠温控：液体、潮湿和长时间接触安全

本项目为主机＋水路＋柔性水垫；制冷方式、电源、开闭式回路、用户范围及市场仍须确认。以下S?是候选标准主题，E是工程建议，V是独立的验证方式；未核完整正文，不给通用电气间距、水温、漏量、压力、故障时长或人体接触温度。

## 产品标准分类入口（2026-10-22，官方范围/目录级）

- [IEC 60335-1:2020及修订入口](https://webstore.iec.ch/en/publication/61880)：家电通用安全，需与适用且相容的专用部分配合。当前详细条款及国别差异待核。
- [IEC 60335-2-66:2025](https://webstore.iec.ch/en/publication/94494)：水床加热器及控制单元。循环冷热垫是否符合定义要确认，不把所有含水产品归入该类。
- [IEC 60335-2-17:2022](https://webstore.iec.ch/en/publication/70369)：柔性电加热器具，官方范围排除水床加热器；页面列AMD1:2026入口，内容未核。不能直接当作水循环垫标准。
- [IEC 60335-2-40:2024/AMD1:2026入口](https://webstore.iec.ch/en/publication/104758)：制冷热泵主机候选，是否适用取决于完整定义/排除项和系统构造。使用TEC或压缩机都不自动决定分类；压缩式另评制冷剂及压力系统要求，未确认前不替用户选择。
- [IEC 60529:1989+AMD1:1999+AMD2:2013](https://webstore.iec.ch/en/publication/2452)：外壳IP分类，不能代替内部液路破裂、冷凝或总成可洗验证。
- [ISO 13732-1:2006](https://www.iso.org/standard/43558.html)、[ISO 13732-3:2005](https://www.iso.org/standard/34077.html)：热/冷接触评估方法入口，不是长期睡眠统一温度限值。

需按销售市场核中国GB及其他当地采用版本、认证类别与整机/部件组合；本次未核对应采用版，不能杜撰GB条号。医疗用途、儿童或特殊感觉/行动能力用户要另行界定风险和适用要求，不按普通成人场景直接推及。

|---|---|---|---|
| SAS01 | 湿区与电气区 | E；S?产品安规：接头、箱体、冷板到PCB/电源的液滴、毛细和喷溅路径 | 实际姿态受控泄漏，记录传播和事后电气检查 |
| SAS02 | 最差泄漏 | E：持续小漏、接头脱开和满盘场景分别定义，断泵后仍可能虹吸 | 最大高差/持续残液下验证；非任意同时故障 |

| SAS04 | 污染与爬电 | E；S?产品安规：水渍、离子残留、冷凝与污染等级假设一致 | 材料/环境证据及湿态复核；不套原AV/ICT毫米值 |

| SAS06 | 绝缘和接地保持 | E；S?产品安规：管路/维修位移不磨损绝缘、断开保护连接 | 维护、热循环及适用机械试验后复核 |
| SAS07 | 外壳/内部防水分工 | S?IP与产品安规；E：分清外部溅水、用户补液和内部泄漏 | 采用的IP方法与内部故障试验分开 |
