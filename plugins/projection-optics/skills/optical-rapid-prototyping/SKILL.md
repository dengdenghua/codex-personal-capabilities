# 快速搭建光学原型



先确认原型的参考输入、当前项目版本和来源范围：源尺寸/角域/谱与功率口径、目标器件真实尺寸、焦距/机械空间及需要保留的接口。已有方案是起点，历史模型名称或规模相近不证明已适配。使用工作台MCP时先发现实际工具；技能本身不安装工作台服务或自动重载连接。



## 工作台入口



1. 用 `optics_list_prototypes`、`optics_get_prototype` 和 `optics_get_scene` 读取基准；选器件前检索来源并核已读范围。没有基准时可以用 `optics_create_prototype` 建明确标注的合成模板。

2. 需要倍率复用时，按 [缩放与验证](references/scaling-and-validation.md) 选择倍率与光源模式。调用 `optics_preview_scaled_prototype`，传 `project_id`、当前 `version`、`factor` 及 `source_mode`。`fixed` 保留光源尺寸，`all` 将光源尺寸也缩放；支持0.01–100倍率。

3. 看参数差异、角度起算、复眼覆盖及确定性光扇。预览只计算，不保存。这里是标量参数加薄透镜/单截面复眼/理想折转示意，不能当真实镜片处方或效率。

4. 用户要求生成候选时，用 `optics_clone_scaled_prototype` 另存独立原型；原项目保持。缩放改变真实尺寸后旧器件引用会解除，重新匹配器件。来源版本冲突时重新读取，不猜版本或重复失败写入。新建调用不是幂等，先回读创建结果再决定下一项。

5. 使用 `optics_export_prototype` 得到迁移JSON；检查名称、备注、历史器件信息的私密性。原始私人资料、模型与数据库不随通用插件迁移。



网页工作台也可通过“倍率缩放”按钮预览后另存，倍率输入支持 `47/39` 等四则算式并显示计算结果；MCP的 `factor` 仍传求值后的数字。若当前MCP连接尚未发现新增工具，可执行随附 [缩放草案脚本](scripts/scaling_draft.py) 处理工作台导出的参数JSON，得到独立迁移草案，再用已存在的导入/预览工具；脚本不打开或改写原生模型。



几何起算后用收集透镜/复眼/棱镜/扩展量专题核接口，再在副本中做少量原生光线验证。绝对效率、谱角偏振、公差、热和实测各自补证；生成或可视化成功不能把候选记为已验收。没有新增来源核读时，原型功能或插件打包不增加学习覆盖百分比。
