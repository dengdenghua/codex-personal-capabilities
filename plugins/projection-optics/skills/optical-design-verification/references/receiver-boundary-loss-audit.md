# 接收面、漏边与终止损失

缩放后重读光学件与监测面的全局位姿、绑定对象、介质、范围和启用状态；监测面随组件移动与实体面自动绑定是不同机制。以少量原生光线验证局部到全局坐标、方向符号与目标面投影。球心、顶点、切面原点和非唯一欧拉角不能直接作差判错位。

DMD 纹理底面、名义微镜中心面、倾斜微镜实际命中面和窗后监测面分别标识。距离虽小，斜入射仍有横向偏移；每条光线投影到明确的统计基准。新数据随附接收面和评价面位姿，禁止仅依赖旧脚本常数。

用户要求的四边调节余量转换为固定目标框，并明确照度参考区、边段位置/宽度、角部区域和统计量。包络、整边平均、九点均匀性与最弱边段不是同一验收条件。有限宽度分段平均不能证明连续边界逐点达标。将本项目明确要求保存在项目配置，不把 0.3 mm、90%、两片球面等推广为通用限值。

用户禁止缩小光斑时，将此约束与有效功率一起保留；不能通过减少照明范围、裁掉失败样本或改变归一分母制造效率提升。调节余量所需的过填充是有意保留的功率分配，应与无用超额外溢区分。

逐面损失先分事件功率和最终去向。透反射事件、回返后的吸收与机壳终止不可重复相加。机壳接收功率不等于机壳首先截光：用路径次序、传播方向和目标面交点区分上游未收集、反射返回、元件边缘与目标外溢。

虚拟面需核真实类型和表面属性；名称包含“虚拟”不保证它无损透射。已有吸收边界的物理含义不明时保留问题，不能为了好看效率将其删除或透射化。共享光学属性的 generic R/T 字段不一定是实际混合/偏振通道系数，应核具体子表与原生事件。

最弱边段单独评估有效样本数和采样变化。用于选型的数据不再作为独立留出验证。早停/OOM、缓存、实际条数不足和分支相关性分别记录；功率稳定不等于局部照度收敛。几何角分布和匀光结果不能证明激光相干散斑降低。
