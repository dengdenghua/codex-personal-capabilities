# 收集镜组的片数、非球面位置与材料



用于结构起算与候选比较，配合焦距和面角联合接受流程。以下比较顺序是工程方法，不是固定片数、折射率或通用验收门槛。



## 从结构基线选择自由度



分清镜片、光学界面和非球面：两片空气间隔透镜有四个光学面，一个非球面镜片可有一面或两面非球面。用 S1…Sn 标识沿实际光路的界面，并明确平面、球面、非球面及对应镜片；胶合界面单独列出，不套用所有镜组都是 2N 个独立界面的假设。



[TI DLPA130A，Collimator Design Example、图 1-7](https://www.ti.com/document-viewer/lit/html/DLPA130A/GUID-0127B91A-6EC9-4D4A-9A49-80418EF0B227)给出的高亮度 LED 起点为：前部小球面玻璃片与后部较大非球面片。前片接近 LED，兼顾热负载与折射能力；后片修正大角光线误差。这是特定应用的典型结构，不由此推定第一片永远不能采用非球面，也不直接套给激光快慢轴准直。



已有模型保留原处方作为对照；新设计可建立球面基线以分清光焦度、间隔与非球面的贡献。按残差选有意义的候选，不强制跑完下表：



| 候选示例 | 需要回答的问题 |

| --- | --- |

| 两片，全部球面 | 曲率弯曲形式、光焦度分配和间隔能改善多少？ |

| 两片，一个非球面 | 哪个面的新增自由度最能改善未被接受的光线？ |

| 两片，两个非球面 | 两个面是否各有必要，还是一个面即可达到相近结果？ |

| 三片，少量非球面 | 分担光焦度后能否改善面形、边厚或公差，收益是否覆盖新增损失与装配复杂度？ |



同一源尺寸/功率/光谱、后级参考面及接受域下比较。各候选使用相同允许焦距、总长、源位调整和机械间隙范围；允许的调焦应记录，不能通过暗改接受条件制造优势。



## 哪个面值得非球面化



先区分源位置与源发射角两个维度。中心源点的大孔径光线有方向残差，可检查球差；仅边缘/角点源失配还涉及离轴像差及场—瞳映射，不能凭轴上光扇判断整个面源已校正。



观察各面上的光线高度、局部入射角与后级误差的敏感性，逐面试验并重新优化。在每次比较中保持同一约束及足够覆盖的样本；光线高度大只说明可能有修正作用，不能单凭高度指定最优非球面位置。



优先尝试圆锥项与少量低阶项，残差明确时再增加项数。保存软件的面形方程、系数单位、径向坐标/归一化方式和有效口径；不同软件的同名系数不可直接假设通用。限制矢高、相对基准球的偏离、局部斜率、面间隙和最小边厚；具体上限来自供应商能力与项目结构。



非球面增加修正能力也增加面形与装调要求。中心表现改善后必须复核源边缘/角点、多波长和偏心倾斜敏感性。[Edmund 非球面说明](https://www.edmundoptics.com/knowledge-center/application-notes/optics/all-about-aspheric-lenses/)支持用非球面控制球差、减少元件的方向；它不替本项目决定放在哪一个面。



## 折射率与真实材料



薄透镜在空气中的起算关系为 1/f≈(n−1)(1/R1−1/R2)。同光焦度下，较高 n 可减小所需曲率组合；厚镜、高 NA 和多片组须用实际处方重算，不能只按此比例缩放。



不要将高折射率等同于低总损耗、低色差或低成本。候选材料至少保留：



- 厂商/牌号、所用目录版本、工作波段 n(λ) 与色散；n_d 只是指定谱线的数据。

- 对实际厚度的内部透过率，以及各界面的实际谱角镀膜性能；内部透过率与表面透过损失分账。

- 温度相关折射率、热膨胀、工作温度/热梯度与安装条件，尤其是靠近 LED 或转换体的一片。

- 可用坯料、模压或研磨工艺、非球面尺寸/面形能力、材料公差与供应状态。



以上选择维度见 [SCHOTT 光学玻璃资料](https://www.schott.com/en-us/products/optical-glass)，其中 TIE-19、29、31、35、40 分别提供热光、折射率/色散、机械热学、透过率及精密模压的进一步依据；本流程未把这些文档的所有参数预设为已核读。



按少量实际牌号重优化曲率和间距，在允许范围重新调焦。宽谱转换光与各自独立准直的窄谱通道分开评价；非球面主要提供几何修正自由度，不能凭非球面数量宣称色差已消除。玻璃/塑料取舍依实际温度、热漂移、透过和制造条件决定。



## 决定是否保留复杂度



每个候选至少记录：逐面面型、牌号、EFL/前焦面/源位、光学包络、带固定分母的联合接受功率、谱角残差、最小边厚/间隙、加工条件及源位/偏心/倾斜敏感性。只有几何光扇时写几何残差和未命中数，功率效率留作未验证。



优先保留满足验收且复杂度适当的候选。有限样本中极小的名义改善须与采样误差及制造敏感性比较；不设一个脱离项目的通用增益百分比。保留更多镜片或非球面时，明确它解决了哪项残差或约束，以及证据来自计算、原生仿真还是实测。



## 材料替换试验与模型绑定



先按实际测量面分别算原件和替换件输出/输入。相同电流但输入W不同并非同一配对试验；不串乘不同运行的分段比来组成端到端链。比较内透与总透时绑定厚度、谱、镀膜及局部AOI、实际接收域、温度、对准和焦面，材料标签不证明吸收是唯一原因。保留多个同时变化的变量及不确定度，受控材料归因与整机候选收益分开。



模型副本按SHA、处方修订、玻璃目录、源/时序和实体材料绑定到试验版本。同名截图、接收器或文件名不证明同一状态；原生实体材料与后续报告更换牌号不同要明记缺口，不能静默替材料或回填日期。发射面IS EMITTING与顶层RAYTRACEABLE各自核，禁用源的标量功率不加到有效源分母；方向apodizer还需aim函数才能解释实际发射域。



原生打开并读到历史非零网格不等本轮追迹。先核仿真汇总、接收器空间/角域、主网格/保存光线与当前源状态；汇总为零而部分缓存非零时保留缓存，未绑定同工况前只给条件比。可用少量确定性光线做面角映射，真实材料损耗与联合接受功率最终另作谱角、源分布及采样收敛验证。
