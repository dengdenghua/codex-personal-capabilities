# 光源架构与多通道设计

先决定光如何产生、转换、合并和分时使用，再把确定的通道交给收集透镜与配色预算。物理器件数量、独立电驱通道、泵浦通道、输出光谱和显示基色数量是不同的数，不能用“4 LED”自动建立四个独立颜色变量。

## 按发光机制选择流程

| 当前任务 | 按需读取 |
| --- | --- |
| LED、多路 LED、蓝泵增强转换绿光 | [LED 机制与 TI 依据](references/ti-led-architecture.md) |
| 激光泵浦荧光体，含色轮与补色通道 | [激光荧光粉流程](references/laser-phosphor.md) |
| RGB 直接激光、整形、匀光与消散斑 | [直接激光流程](references/rgb-laser.md) |

混合方案在各支路按实际机制建账，再合并接口；不把泵浦激光的面角分布直接赋给荧光输出。TI 原文版本、核读位置和结论边界见 [激光资料依据](references/ti-laser-sources.md)。

## 通道定义

给每个节点稳定 ID，并建立通道表：

| 项目 | 必须分清的含义 |
| --- | --- |
| 器件与驱动 | 单颗/阵列/封装、独立驱动组、电流波形和可同时工作的组合 |
| 光学角色 | 直接显示、泵浦、波长转换、偏振回收或混合；一个角色不自动等于一种基色 |
| 光谱与功率 | 电学输入、泵光、吸收泵光、转换输出、残余泵光；所在参考面及 CW/平均定义 |
| 发光与收集 | 有效发光区、位置、介质、空间/角分布、偏振及相干条件 |
| 时间与热 | 帧内时段、器件 duty、脉冲能力、结温/转换体温度及标定工况 |

明确当前已知的目标白点、屏幕光通量/色域、芯片与后级面角接受、体积、散热和成本约束。真实发光面不由封装外形或器件数量直接推出。

## 比较架构与瓶颈

根据任务比较 RGB 三路、蓝泵增强转换绿光、激光荧光粉、RGB 直接激光及混合等候选。只为实际候选建立路径与接口，不因有模块就枚举全部架构。

对每条泵浦—转换路径画出能量关系：入射泵光 → 被吸收部分 → 转换与逃逸输出；未吸收的透射/反射光单列。如果已用实测的总转换输出，就不再把同一泵浦贡献加一次。残余泵光是否能作为显示蓝光，需要实际路径、谱和时序证明。

增强转换绿光可能受红光可用量、白点、占空、后级接受或温度限制。评价同一目标白点下的端到端可用输出，不能用某个单色光通量的增幅代替整机增益，也不预置一个通用增益倍率。

同一波长/时间/偏振下，多发光区合束需检查亮度及面角占用；不同颜色、时段或偏振可以通过不同机制共享路径，但不因此自动具有相同的发光面、扩展量或损耗。逐通道定义接受域，不能把所有通道 G 简单相加或全部当成一束来判定。

## 时序、谱形与热

用“显示时段 × 驱动器件”的表表达同时点亮和泵浦组合。互不重叠的显示时段占空和受帧周期约束；不同器件可以同时点亮，因此各器件 duty 相加大于 1 不一定出错。器件脉冲/平均限制分别核对。

功率、电流和谱形不默认线性；同时驱动转换绿光与外部蓝泵时，可用经过标定的输出函数或查表 F(Igreen, Ipump, 温度, 时段)。只有验证了固定谱形和可叠加性才简化为线性通道，不能直接把泵浦 LED 的 xy 当成新增显示基色。

把电学损耗、转换损耗及未送达目标的光能分开；未到屏幕的光不一定全部在同一器件吸收。记录散热位置、温度依赖、峰值/平均工况和驱动能力，暂缺实测时给条件预算。

## 交给下游的接口

- 收集组：每个发光区的有效宽高/位置、角域、谱线、功率、机械与热基准，以及目标面角接受；据此确定焦距和准直分布。
- 合光/棱镜：每一路的入口位置/方向、谱线、偏振、有效口径与逐次过膜路径。
- 配色亮度：已经识别的输出光谱/XYZ、时段、器件组合、逐色损耗和功率分母。架构选择与固定通道的白点求解分别处理。
- 系统验证：共同参考面的白点、有效通量、面角联合接受、热限制、数值假设和待测项。

直接激光照射 DMD 时另交付波长/带宽、照明瞳孔、器件阵列与倾转几何、投影接受和入射功率密度/时序，供衍射与热验证。若当前环境提供 `coating-ai:dmd-design`，读取其能力与适用范围后再使用；工具不存在时仍可完成架构和接口，不能报告衍射计算已完成。LCOS 的后级验证采用其实际偏振与像素模型。

交付通道表、能量与合光路径、时序表、受限因素、候选比较及接口条件。没有测量或原生追迹时交付条件方案，不声称新架构增益已实现。

## 独立使用与工具

本 Skill 可独立用用户给出的条件评估光源架构，不要求先调用整机 Skill。需要私有多源模型/算表时，通过已连接工作台检索“多通道、蓝泵、转换绿光、混合光源”并核来源；原生验证配合当前可用 LightTools/Zemax 控制工具。工作台若只有固定 RGB 预算，先保留完整多通道映射，不把泵浦依赖强行压成独立 RGB 输入。

读取激光阵列规格先分别定位个体芯片、串并连接、端电压参考、电流自变量和整体输出功率；图标题与脚注冲突时保留分支，不能将串联电压再乘并流倍数。绝对最大、初始特性、估计或括号参考、运行/储存温区与实际批准版分开。个体角模的平均绝对值、均值矢量、RMS和单颗上限不互代；负号或零的发散列不能默默当正全宽/零扩展量。Pe−Po仅作同工况源级差值，驱动损耗及下游吸收另账；Tm/Tc不默认等Tj。

复用封装概念或热测试资料时，按 [RGB激光](references/rgb-laser.md) 中“概念封装与测温边界”核热阻、测温位置和终版状态；拼接外包络不代真实发光域。

出货样件截图与实测方案比较时，按 [RGB激光](references/rgb-laser.md) 中“样件统计与测量口径”核CW、电流、温度和平均/最大值定义。

追Origin光源历史比较时，按 [RGB激光](references/rgb-laser.md) 中“样件与图源身份”区分样件、手填规格曲线与同名工程。

审计荧光系统时，按 [RGB激光](references/rgb-laser.md) 中“泵浦分母与替代源”逐段记录泵浦/接受参考面、测量工况和替代源适用边界。

审计光源热工况与分段预算时，按 [RGB激光](references/rgb-laser.md) 中“器件测温与参考面链”先绑定传感器和物理参考面，再使用温度及效率。

验证激光荧光色轮时，按 [RGB激光](references/rgb-laser.md) 中“色轮驱动与动态负载”分离速度、显示序列与关光窗，保留长时安全缺口。

评估荧光粉包覆时，读 [RGB激光](references/rgb-laser.md) 的“包覆与最终逃逸边界”，区分材料产率、前后光阑输出和整机收益。

复用激光电光或杂光测试时，按 [RGB激光](references/rgb-laser.md) 的“电光功率、接受域与散斑协议”绑定端电学功率、光阑接受和测温/相机条件，再交下游预算。

复用结温原表、色轮预算和双色峰值时，按 [RGB激光](references/rgb-laser.md) 的“热计算源与时序分母”核标定、峰谱定义、功率参考面和真实器件身份。

用热敏算表、维护建议与烧损阵列数据建预算时，按 [RGB激光](references/rgb-laser.md) 的“热敏、驱动与功率修正”先绑定传感器标定、额定和修正功率定义。

复核激光报告收光修正与封装拆解时，按 [RGB激光](references/rgb-laser.md) 的“收光修正与封装证据”核分母、舍入区间和局部材料接口。

激光荧光与直接RGB混合方案，按 [激光荧光流程](references/laser-phosphor.md) 的“空间合光与散斑份额”核中心区接口、功率分母及方差假设。

多版方案的光通量增益与分色DMD负载若来自不同情景，按 [跨方案亮度与通道负载比较](references/laser-phosphor.md) 统一基线、白点、时基和受限通道；不能把跨通道峰值当通用器件上限。

核有限吸收深度和热态发光时，按 [吸收深度与局部发光](references/laser-phosphor.md) 统一吸收分母、热源位置和发光权重，再给下游源接口。

核荧光转换效率时按 [激光荧光流程](references/laser-phosphor.md) 的“辐射功率比与光子量子产率”区分 W/W、lm/W 与 photon/photon；波段、吸收分母和参考面未定义时不要把列名当作量子产率。
