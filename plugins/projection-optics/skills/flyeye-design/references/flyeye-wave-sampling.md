# 复眼复场接口与采样诊断

从原生模型读出全部曲面，并保留读取数量、截断状态、每项 API 状态、材料、世界姿态和有效边界。CAD 边缘半单元及角部片段计数不等于完整有效单元数。曲面坐标基点、球心和顶点须结合原生定义及边界验证，不能仅由半径猜测。

双面复眼应分别保留入射界面的相位作用、材料内复场传播和出射界面的相位作用。参考平面上的球面相位切片是标量近似；它不自动包含曲面上的真实传播距离、Fresnel复响应、偏振、过渡区和制造表面。需要原生等效或独立方法验证后再采用。

复杂场接口必须标注输入面的身份。把随机相位直接施加在复眼入口，只能作为该段的条件探针；不能声称真实扩散片到复眼之间的光学作用已经接通，也不能在几何散射结果上重复添加独立扩散相位。

自定义材料应保留原始折射率表和实际插值方式。API子表空列表不证明材料没有数据；可在工作副本嵌入自定义材料后核原始序列。按确切表节点做方法探针不证明RGB中间波长插值一致，不能悄悄以线性插值替代Hartmann。

功率守恒、零转速不变及正反向传播一致只是算子控制检查。分别变化像素间距、计算窗口及曝光帧数，再比较共同物理区域的强度与复场。频谱接近Nyquist边缘时有欠采样线索；功率守恒不能排除相位混叠。窗口增大时保持相同像素间距，像素加密时保持相同窗口，避免混淆两种误差。

曝光按强度积分。旋转扩散片通过同一个连续OPD屏的坐标变换生成时间帧，不为每帧重新抽取随机屏。当前局部接口的均值图不自动是屏幕散斑；源相干谱、粗糙屏幕、观察光学、像素积分及曝光条件未闭合时保留屏幕散斑对比度为空。

依据：[Ansys角谱传播采样限制](https://ansyshelp.ansys.com/public/Views/Secured/Zemax/v25101/en/OpticStudio_User_Guide/OpticStudio_Help/topics/Angular_Spectrum_Propagation.html)。本地条件探针显示功率守恒而强度仍对网格敏感，项目数值与未验项应保存在项目审计中，不推广为行业限值。
