# 目标面暗区与联合接受诊断



先把合同均匀性展开为接收面、格子/测点、窗口、单位、分子分母和温态。最低/平均、最小/最大、总体标准差和归一CV不同；较小总体波动仍可能隐藏少数暗格。软件图像目标还须绑定绝对功率及真实接收器分辨率，显示重采样不补物理采样。



用同一到达光线集合和共同输入功率分别保存空间域S、角域A、联合域及两个单域拒绝、两域同时拒绝的互斥账。仅空间图、联合图与角拒绝图逐格闭合；局部联合/空间功率比只在分母非零处定义。空间和角边缘分布相同不保证联合接受相同。拒光差额须继续定位端口和实际吸收，不直接指定为实体热。



两阵列配准用实际局部单元中心/索引记录，并以功率加权核同单元和相邻单元的最终接受。串单元身份是诊断证据，不能在未核设计共轭和最终目标前自动删光，也不把删掉的光从源分母中移除。



试验场镜或中继非球面时可保持顶点曲率、中厚、材料与中央共轭，单独改变圆锥常数以区分一阶焦度与有限孔径法线。旋转圆锥面k从弧矢四阶项进入；还须核曲面域、连续厚度/间隙、斜率、实际接受与制造。保持一阶矩阵不证明有限孔径像差相同，负k不作为通用推荐。



把有限面形试验、球面对照和源/谱采样契约冻结，训练加密后再固定选型。比较贡献时保留相同过填充、光源样本、光谱节点、口径和接收域，只改待考变量。新增验证结果不能参与原冻结选型；最弱格随样本变化时保留超差，另声明加密方案，不放宽门槛或把积分稳定当最低值收敛。
