# 复眼与匀光设计



区分光源复眼与光机复眼；明确入口面角分布、目标面/overfill、接受角、波长与相干性、结构型式和中继倍率。



## 器件定义与起算



分别记录 x/y 节距、单元有效通光宽高、过渡区、曲面形式、单元焦度、阵列行列数、有效口径、边缘残缺单元、基片厚度和材料。节距、有效单元宽度、阵列口径和整体外形不混用。



理想薄透镜重叠成像中 Wtarget/Wcell≈Htarget/Hcell≈frelay/fcell。单个标量倍率无法消除单元与目标的纵横比差；比较单元比例、旋转或分轴中继，记录相应角接受代价。倍率至少覆盖两轴只是一阶几何起点，不证明均匀性。



空气中薄单元几何半角可用 atan((有效半宽)/fcell) 起算。入射角域、单元名义 FOV、最终芯片光锥分别定义。双面基片需包含折射及材料内传播；两片阵列间距不能自动取 EFL。



## 阵列到目标面的验证



确认第一阵列子束在第二阵列的落点及对应单元；扫阵列间距、x/y 偏移和绕轴旋转，再核中继成像和目标边缘。区分每单元权重、串单元、过渡区截光和芯片过填充；增加单元数不保证均匀性单调改善。



以同一源、同一接收面和定义的指标比较二维照度、角分布、联合功率与颜色分布。几何光扇用于主路径与配准，真实面源统计用于匀光/功率；独立采样检查条纹与边缘漏光。



分轴 Fresnel 数 FNx=ax²/(λf)、FNy=ay²/(λf)，a 是有效半宽，单位一致。面积代用量不能隐藏窄轴的衍射；相干激光输入出现干涉/散斑时采用适用的波动模型，不以普通强度追迹认定波动效果。



交付单元处方、阵列及共轭定义、入口和出口接受条件、损失分账、配准公差及未验项。材料、温度、工艺、镀膜和热负载按当前供应数据确认。



## 资料与执行



本 Skill 不依赖其他设计 Skill。历史资料通过已连接工作台搜索“复眼、单元、共轭、配准”；只读相关证据。原生建模配合可用 LightTools/Zemax 控制 Skill，模型使用副本，工作台符号预览不当真实复眼处方。



## 条件性专题



来料与老化、图纸/原生纹理对应、裁切胶合、焦距定义、历史测试和衍射拟合，按需读取 [专题证据与诊断入口](references/case-evidence-routing.md)。



目标面暗格、分区拒光或中继候选比较，读取 [分区与联合接受](references/panel-joint-domain-diagnostics.md)。



中继片数沿用当前项目约束或已记录的用户偏好；两片球面优先属于设计起点，不作为所有复眼架构的硬性限制。



接通相干复场或动态扩散片时，读取 [复场接口与采样诊断](references/flyeye-wave-sampling.md)，核真实双面、材料插值、输入参考面和空间/时间采样；标量相位切片作为有条件近似。





区分主瓣与旁瓣、绘制理论角域或实际二维角分布叠图时，读取 [主瓣与形状包络](references/main-lobe-shape-envelope.md)。主瓣F数与旁瓣功率分开报告，入口接受域不直接等同出口理论角域。
