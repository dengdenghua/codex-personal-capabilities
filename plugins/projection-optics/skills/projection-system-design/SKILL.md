# 投影光机系统设计



需要快速建立可视化参数候选或按倍率复用方案时，可直接使用 `optical-rapid-prototyping`；后续仍按这里的系统接口分别绑定真实源、芯片、匀光、棱镜和测量基准。



用于跨器件系统设计；各专题可直接使用，无需先经过本 Skill。先确认目标芯片/架构、源、白点/光通量、照明与投影接口、结构和热工况。



## 系统接口



沿光路建立节点表：介质与波长、参考面/局部坐标、空间区域、方向域、含能量口径、通道/时序/偏振状态和前后功率。相邻器件必须用同一接口定义，不能把源面、复眼面和芯片面的数值直接拼接。



先确定扩展量与能量瓶颈，再建立源尺寸—收集组焦距—面角分布—匀光器—棱镜/芯片—投影入瞳之间的约束。各器件的单项最好不等于端到端最好，比较同源下的有效接受功率、白点、均匀性和可制造性。

## 工具组合



设计 Skill 描述方法，LightTools/Zemax 控制插件负责原生建模与追迹，工作台 MCP 负责资料/参数原型及其版本。连接存在不等于模型已验证。工作台一阶光路示意不能冒充原生处方或波动/偏振仿真。



激光照射 DMD 的衍射与热问题由验证专题组织；目标环境若有 DMD 计算插件，先核其阵列、相干和功率模型范围。适用性不足时交付待验证接口，不把近似输出提升为整机效率结论。



使用工作台先读项目与版本，复算/预览后按授权保存；参数与场景显式联动。已有控制插件继续管理各自会话、备份和任务状态，不另开重复服务器或接管不明模型。



交付系统接口、预算、器件选择依据、已验证/未验证矩阵及下一阶段约束。新的案例数值不自动进入通用标准；私人模型与资料不进入公开迁移包。



采购或设计投影镜头/模块时，把参考器件尺寸、架构、盖片和棱镜、焦平/端位、频率参考面、光谱及检测权重、屏距起点、水平屏宽与shift/offset分母一起列在接口中。可调焦范围与性能保证范围分别记录。BFL、机械法兰距和介质后的约化传播长度不能互代；未定接口或疑似单位保留原值并标待批准。模块亮度连同白点/驱动/温态，照明用电与整机用电分别预算；目标值、可接受边界和历史示例不混用。



复用镜头或光机规格先核实际架构与供货边界：交付总成、排除件、完整光路示意和最终系统装调责任分别列。旧平台升级光源功率时，历史可靠性保证、局部限制温度和冷却参考工况须重新对接；旧工况不能直接证明升级后合格。部件、总成与整机的光学/驱动限值保留各自工况和批准变更，不要求名称近似的数值自动一致。



审计镜头基础定义时，记录正向投影或反向分析的物像方向、有效焦距主面与后焦距末面基准。等效薄透镜只作近轴接口；物理厚度、折射率加权光程和法向约化传播不互代，倾斜棱镜须实际几何。图像F数通常以入口瞳而非直接以物理STOP定义；有限共轭工作F与物方NA另核，不能据某个F数推无截光功率。真实芯片料号/节距优先于名义英寸反推；Nyquist、投射比与视场接口各保留参考面，不自动生成验收MTF限值。



比较光源架构时，先绑定每个方案的源谱/空间角分布、时序和功率分母。泵浦光学W、荧光输出W及整机电学W分开，色段有效角、百分比占空比与Spoke消隐只按一次归一化；平均电功率需实际驱动波形。分支末级效率和混合光XYZ逐项核，不用统一效率覆盖方案。原报告材料表/正文、文件名/芯片尺寸冲突保留并追批准原工程；显示分辨率不能当物理像素阵列。



装调流程按版次保存“调节动作→观测域/基准→定量判据→通过/返调/返修”关系。不同通道、聚光组、反射镜、治具及机械支架的步骤可能随版本变化，不把旧版旁瓣/居中要求并成新版门槛。机械基准变动后复核实际光学域；单色全域清晰、进入光阑和最终带工况的通量/功率验收分别记录，缺门槛的判断框不认已通过。



系统引入微结构衍射时，周期电磁求解与光线功率传输建立明确接口。先确认器件处方/材料和版本、源谱角偏振/相干、BSDF归一与真实瞳域；已含材料反射或绝对衍射功率的表不重复乘同一损失。来源同图表的不同格式/汇报不累计独立试验；不同像素节距或球面替代非球面的案例不能直接承诺实样性能。



激光DMD方案先区分闪耀级次匹配指标、有限阵列标量衍射和真实材料/倾转/偏振电磁模型。候选角搜索最大值若在边界，回查整数级次条件及连续角范围，不能直接称精确闪耀解或最大效率。角投影与倍角未必可交换；所有示意标记用与曲线相同的坐标定义。镜间隙整数像素化会改变有效镜宽和填充率，保留目标几何、离散几何及收敛证据后才与真实器件绑定。



含衍射器件的系统先检查角坐标、平面内或圆锥条件和正背面数据。固定入射角的传播级次须满足实际出射方向余弦范围；全局级次上限不作每个入射条件的充分判据。束宽的斜入射投影和anamorphic倍率改变接受域，不直接表示效率。文档公式、图示和命令行存在冲突时保留原定位，用带明确条件的独立几何推导与小型基准模型核对，不冒称厂家勘误。



正背面散射响应分别绑定实际输入/输出侧、角约定及材料；双侧数据齐全不代表两侧响应相等。数据版本可能只有相位分支或序列化差异，必要时比较同基底的完整归一复场来判断本范围内的响应等价；不能从存储等价推断真实材料、器件或独立测量次数。



复用微结构模型先按内容身份核原工程、脚本、任务/扫描文件与输出表的生成链。保存的镜宽/周期只支持有条件的几何面积比，不直接当实际填充率或效率；端点位移角不自动等于镜面法线倾转。源变量、散射输入角、软件工具选择与材料实际引用分别对接后，再评估系统接受功率。



谱角数据预算先核真实坐标与默认偏振、侧和归一；完整存储点的功率和仍需源分布及实际接收域加权，不能直接作为整机效率。角变量按原图/方向余弦及命令接口绑定，不按符号猜测极角或掠入射。



输出表只列部分级次时，全级次总反射与有限接受子集分别预算；包含率保留分母，不能沿用为占入射功率的比例。保存角接近仍须比较完整方向余弦，生成时模型和执行状态另核。



更换棱镜/盖片或复用镜头后焦时，按 [平板补偿与温态接口](references/plate-compensation-and-thermal-interface.md) 同时核球差、色差、真实共轭及可实现的补偿律。



核热态变焦补偿时，按 [平板补偿与温态接口](references/plate-compensation-and-thermal-interface.md) 的“主动与被动热补偿”同时评价MTF、焦距和齐焦，保存可实现的位移律与离散采样范围。



需求表含多次确认列时，保留每列定义、工况和TBD，不自动用最新空白继承旧限值。将物理芯片/分辨率、输入解码、中心亮度/整机光通量、寿命/MTBF/CLO、shift分母与目标/预测/当前功率分别建项。备料单的料号、版次、供应商和改样任务只能提供批准BOM的候选；裸库存和单项配套量不证明完整可装数量，串式尺寸或曲率摘要不构成完整光学处方。



审计光机案例的分段效率、统计截图、平台化或降本时，读 [效率链与平台化证据](references/stage-budget-and-platform-evidence.md)，分别核参考面、分母、工况与BOM/工时定义。



核屏幕需求与光源资源联动时，读 [需求反推与资源联动](references/system-requirements-and-joint-budget.md)，把可达白点上限、黑场与环境条件接到同一预算。
