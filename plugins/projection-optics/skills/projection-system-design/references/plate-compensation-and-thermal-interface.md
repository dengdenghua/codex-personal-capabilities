# 平板补偿与温态接口



平行平板在汇聚光中可改变像面并引入球差和轴向色差。匹配ndt光程、d/n约化传播或单一后焦都不足以证明可替换；绑定物像方向、主面/末面基准、介质、真实光锥/孔径角、远心程度与波长，至少同时复核LONA/AXCL等明确定义指标和实际全场多色性能。Abbe数近似不替完整色散和部分色散。远心初级理论中的离轴项为零不推广到倾斜、楔差、偏心或非远心实物。



平板色差近似(n−1)d/(Vn²)和球差近似(n²−1)d u²/(2n³)均需指定量纲、符号、角变量和参考波长。F数到u的映射先核共轭/瞳域，无法恢复光锥时保留球差表未闭环。解析近似、保存软件截图和真实原生复算分别登记；历史选材厚度不成通用清单。



温态模型同时保存绝对/相对空气折射率、温压和厂家热光系数/适用域，区分目录与模压后玻璃批次。均匀各向同性膨胀s下R→sR、k不变、高阶弧矢A_p→A_p/s^(p−1)；支撑高度与面弧矢共同决定中心间距，不能仅放大厚度。非均匀梯度/应力须相应模型。逐温独立最优间距不证明被动机构可制造；核行程、热位移律、迟滞和实际温态MTF，固定像面不保证焦距或色差稳定。



## 主动与被动热补偿



分别定义MTF、有效焦距、固定像面及变焦齐焦目标；绑定谱权重、场/瞳、参考面和频率。最佳像面漂移、组元行程和焦距漂移不可互代。逐温优化的间距表要落实到可实现的主动控制律或被动机构：传感器位置、校准、行程、热时间常数、迟滞及实际约束都影响结果。拟合残差只是有限表的算术诊断，无原处方不能称重建了最优控制。



被动多筒补偿按真实装配计算有符号Σ(±L_i α_i)ΔT；Lα是长度/温度，若资料省略ΔT则核它是否描述每度位移。恒定CTE、均匀温度的几何起算还需塑料蠕变、胶、约束及梯度验证。为敏感焦段选机构可能降低另一焦段MTF；核多目标阈值，不能把局部调焦改善推广到所有状态。少数温度与焦段节点通过需加密最坏点、边界及切换区，不能证明连续全域。



原生热建模先核各热光/尺寸参数是否实际启用：目录系数存在但环境折射率修正关闭会漏算热光项；默认薄壳隔圈模型须与实际接触/径向支撑相符。供应商折射率的绝对/相对空气、参考温压、波长单位与适用域分别绑定，未核数据不以热光GUI截图替代。
