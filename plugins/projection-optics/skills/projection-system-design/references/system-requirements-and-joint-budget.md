# 需求反推与资源联动



## 屏幕到资源的共同条件



用有效画面尺寸、观看位置和实际屏幕响应区分投影白场、投影黑场与环境贡献。理想均匀朗伯屏下，环境全白全黑比可写成(Lp+La)/(Lb+La)；非朗伯屏或棋盘格需其实际方向与回返模型。需求给定的黑场不能被零黑场极限替代。投影输出端的白点、温态、积分区域及平均或峰值一起绑定。



先由屏幕要求反推每个规定条件的最低有效通量，再求光源在同一条件下的可达白点上限。固定原色、矩形时序和灰度传输时，XYZ解给各通道Y贡献；由ON光通量换成占空比，最大白光同时受总有效时间、消隐和逐通道驱动上限约束。真实谱色随驱动或温度变化时重算XYZ，不能只乘保持率。



将实际可供值与目标值比较后再传到后级，不能在资源不足的条件中仍假定目标通量全部可供。源输出、传输和屏幕变化是否独立须明确；同一热衰减不重复计损。名义通过、指定离散组合通过、连续最坏情况和统计良率分别报告；为获得通过修改要求时保留原要求与授权变更。



## 分母与参考面



按源半空间、已收圆锥或后级入射功率分别建立效率账。均匀辐亮度的扩展量容量比只给规定域的上限；非均匀源需带权联合分布。空间角度边缘分布相同仍可能有不同有效功率，已占相空间容量比例也不等于实际源功率接受率。



投射比的末面到屏幕距离与主面共轭距离分开。像素节距对应的Nyquist频率与芯片侧或屏面侧参考一起传递，它不自动生成MTF验收值。均匀性记录min/max、min/mean或CV及采样位置，不按名字近似互代。局部灰度效率没有覆盖实际偏振、衍射、温态和实体镜组时保留缺项，最终结论只对应已验证条件。



## 使用证据



新案例的材料、效率、通量和误差限值留在项目证据中。公开器件或规范按实际版本、页段和条件核读；源码哈希、可复算附件和原生局部核对不替代整机或实测验收。
