# 效率链与平台化证据

## 分段预算

将光路节点按“版本/架构、空间面、方向域、源谱/通道、时间权重、偏振、计量单位、被排除损失”建表。局部出口/入口效率与整链屏幕/光源效率分别给分母；Overfill前后不同的起点不共用一个“光机效率”。相邻比值的乘积应回到相同首尾端点，打印阶段比先舍入时保留其链积残差。

流明、辐射W、电学W和热耗散各自成链。谱经过滤光/接受域改变后，W/W与lm/lm可能不同；两个相同流明标量不证明同谱或同工况。图纸布局长度不能自动作为焦距或物像缩放倍率，源面半角与芯片F数先核实际参考面和约定。

原报告说明排除镀膜、偏振或反射损失时，将排除域保留在结论；不凭历史统一系数补足。光损失差值总和闭合不证明各段精度或全部转为某器件吸收热。相邻出口略大于入口时保留原值，先核舍入、采样和同域定义，再追是否物理增益。

## 统计与平台化

读取公差截图先辨直方图分区数、实际样本数、累计计数、均值和拟合参数。图有高斯拟合不证明制造分布、独立性或合格率；需变量单位、误差分布、相关性、样本量和批准性能边界。坐标轴或控制标签的小数字不能移成Monte Carlo样本量。

BOM分别列使用数量、独立料号、完整总成范围、报价时点/采购规模、良率和固定支持费用。分类小计与成品总数不相等时追遗漏项或范围，不补假设数凑成本。件数减少、料号减少、治具类别/数量减少分别计算，不能直接证明相同百分比降本。

工时降幅与每小时产出变化的分母不同。HPU有降低，也须核人时/机时定义、工位并行、停机、批量和良率后再讨论产能或交期。图注量产阶段、流程版次与调试成熟度保留；流程小字未核或没有定量门槛时，不称流程/质量验收通过。
