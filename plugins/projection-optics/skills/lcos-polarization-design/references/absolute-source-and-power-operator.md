# 绝对源功率与非相干端口算符



## 源分母与偏振损耗



源前半空间功率、已收集圆锥功率、偏振后PBS入射与成像端口分别定义。给源功率时同时记录发光面积、角谱、温态和是否为光学或电输入。带权联合面角域用同一条光线的交点与方向判定，不能把两个边缘接受率相乘。非偏振源通过被动偏振片后的高主分量占比不能替代绝对透光率。初始相干矩阵在真实Fresnel后继续传播，不每面重置为非偏振；各反射、吸收、空间与角度裁光、偏振拒光分别记账，拒光不自动成为某器件热。



## 功率响应缓存



不同模式按功率互不相干相加，且只需指定端口功率时，可将每模式的复传输J化成Hermitian功率算符H。输入输出若已规范化到同单位功率正交态，H=J†J且p=tr(HC)。若软件采用非单位功率场基，先引入正确输入输出功率度量和换基，不能直接据欧氏J†J判被动性。输入相干矩阵C保留绝对权重和实际偏振，不把接受后的集合重新归一。



波长与方向节点共享可比的输入坐标和功率基底；旋转局部基底时显式变换H和C。邻点H的非负凸插值保留Hermitian、半正定和0≤H≤I的被动边界，负插值权或外推没有这一保证。检查圆锥边界插值模板与真实查询域，缓存网格、直接复响应探针、实际源加权功率以及层数/谱角采样分别核差；有限探针通过不能升级为全域误差界。粗缓存失败保留，精缓存选择与验证数据分开。



H消去了输出公共相位及完整输出场，不能据H恢复输出偏振、相干PSF、干涉或模式相干重合。只有Tp/Rs等强度谱不能生成一般非对角H；须有相对相位复响应或等价完整输入功率算符。需要输出偏振时传播J C J†，需要相干像场时保留统一参考的复场。



## 玻璃参考面与验收



空气共轭中插入平面玻璃段，t/n约化距离只作近轴起算；真实有限角另追入口Snell、传播交点和联合面角接受。空气光锥、内部光锥和倾斜膜面绝对AOI分开绑定法向、介质与端口。坐标展开不作为额外实体镜面或功率增益。



总功率的积分加密不证明分区最低值、连续极值或均匀性收敛。分别改变光线数和波长节点，固定同一源样本及处方，保留种子与分母；同时改变两者的比较不能单独证明谱收敛。积分端口CR、屏幕环境CR、原生局部核对和整机验收分别报告。历史案例参数和失败后源功率提案留项目证据，通用Skill不固化为推荐值。
